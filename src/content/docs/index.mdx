<CardGrid>
  <Card title="One contract" icon="pencil">
    Implement IPlugin. The framework drives load, enable, disable, and unload, and refuses packages that break the contract before they run.
  </Card>
  <Card title="Isolation" icon="puzzle">
    Every plugin gets its own collectible assembly load context. Unload is verified, and a failing plugin does not take the server down.
  </Card>
  <Card title="AOT-style providers" icon="rocket">
    Official providers hand the core a compiled CLR assembly: precompiled, or compiled from C#/F# source at load. Every plugin runs in its own collectible ALC on the CLR.
  </Card>
  <Card title="Two carriers" icon="server">
    The same managed core runs under LeviLamina and Endstone on Windows x64.
  </Card>
</CardGrid>
