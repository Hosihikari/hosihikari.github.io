import { Card, CardGrid } from '@astrojs/starlight/components';

<CardGrid>
  <Card title="One contract" icon="pencil">
    Implement IPlugin. The framework drives load, enable, disable, and unload, and refuses packages that break the contract before they run.
  </Card>
  <Card title="Isolation" icon="puzzle">
    Every plugin gets its own collectible assembly load context. Unload is verified, and a failing plugin does not take the server down.
  </Card>
  <Card title="In-process loaders" icon="rocket">
    C# and F# source is compiled AOT to IL; the loader loads it into a collectible ALC, and the plugin manager drives lifecycle. Precompiled assemblies use the plugin manager's built-in path. RpcLoader is the out-of-process loader: an official RPC bridge.
  </Card>
  <Card title="Carriers" icon="server">
    The same plugin manager runs under LeviLamina, Endstone on Windows and Linux, and the self-hosted Linux carrier (BDS 1.21.3).
  </Card>
</CardGrid>

## Start here

- [Running a server](/server/) — pick a carrier, install it, and keep it alive.
- [Writing plugins](/develop/) — the contract, the package format, and the loaders.
- [Embedding the manager](/embed/) — host the manager in your own process.

The documentation is also available in [简体中文](/zh/).

RpcLoader is the out-of-process loader: an official RPC bridge for plugins that cannot be compiled to IL.
