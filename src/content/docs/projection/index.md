---

Hosihikari Projection turns native carrier and Bedrock Dedicated Server APIs into managed .NET types. It is an independent context, developed alongside the framework.

## What it provides

- Managed binding assemblies for the carriers and for Bedrock Dedicated Server: `Hosihikari.Bindings.LeviLamina.Interop`, `Hosihikari.Bindings.Endstone.Interop`, and `Hosihikari.Bindings.Bedrock.Interop`.
- The BDS MCAPI projection used by self-hosted servers.
- `BindingGenerator`, the generator behind those assemblies.
