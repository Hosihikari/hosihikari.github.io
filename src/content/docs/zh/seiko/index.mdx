  <Card title="CLI 与 MCP" icon="rocket">

## 从这里开始

- [安装 Seiko](/zh/seiko/install/) — 安装 `sk` 与 `seiko-mcp`，并校验下载。
- [快速开始](/zh/seiko/getting-started/) — 创建安装根、添加 sei、重放锁。
- [命令参考](/zh/seiko/commands/) — `sk` 的完整参考。
- [发布 sei](/zh/seiko/publishing/) — 打包构件并提交到官方索引。
- [MCP server](/zh/seiko/mcp/) — 让 agent 连接安装根。

Seiko 只安装文件，不构建、运行或加载你的项目；文件在运行期意味着什么，是项目自己的事。例如 [星光框架](/zh/framework/) 会在 Seiko 放好文件之后从 `plugins/` 加载插件。

本文档也有[English](/seiko/)。
